### Basic audio IO and FX through the command line.

### Usage 

#### Devices

- --list : Displays a list of available devices
- --input _ : Selects index _ as the input device
- --output _ : Selects index _ as the output device
- no args picks default input/output device

#### Mid-stream

- q | quit : stops taking input
- fuzz : applies fuzz effect
- dist : applies distortion effect
- vol _ : sets volume to _
